ShapeRack 0.2.2 is installed.

Load ShapeRack in FL Studio:

1. Open FL Studio (64-bit).
2. Select Options > File settings > Manage plugins.
3. Enable Verify plugins, then click Find installed plugins.
4. Open a Mixer insert's effect slot and select ShapeRack from the plugin list.

The VST3 plugin is installed in the standard Windows VST3 folder:
C:\Program Files\Common Files\VST3\ShapeRack.vst3

ShapeRack starts with a quarter-note Volume pump. Adjust Amount or Mix to taste.
Select Filter, Pan, or Drive and click its OFF button to add another effect.
The button lights up and says ON when active; click again to switch it off.
Sync follows the project tempo and keeps cycling while you preview notes
with playback stopped (SYNC PREVIEW). Starting playback realigns the curve
with the song (SYNC PLAYING). Free sets an independent rate in Hz.

Bend is the default editing tool. Nodes, Draw, and Line remain in Edit.
In Bend, drag directly on a curve point to move it up or down, or drag
a segment diamond to bend the curve. The pointer stays an arrow over
blank graph space and becomes a vertical editing cursor over a handle.
Alt-drag a segment to bend it from other tools; Shift gives fine control
in Nodes and Bend. Snap adjusts vertical values. The 17 point times
stay at equal divisions of the cycle.
Use Undo, Redo, and Tools for copy/paste, invert, reverse,
and flatten. Shape buttons replace the current module's curve.

RACK PRESET recalls a complete factory or personal rack preset.
Save... opens a naming box and adds the current rack to your library.
Import... loads a shared .shaperack.json file; use Save to keep it in your library.
Export... saves a portable file through the Windows file dialog.
Refresh picks up presets saved by another ShapeRack instance.

Setup creates your preset folder and includes five portable files in Factory.
Presets folder opens it in Windows Explorer. Save keeps personal presets here.
Existing files survive updates and uninstall. ZIP installs create it on first use.

Your preset library is stored in:
%APPDATA%\PRISMM\ShapeRack\Presets

Version 0.2.2 includes a 12 dB/octave Butterworth filter and antialiased drive.

If you selected CLAP, rescan the CLAP plugin folder in a compatible host:
C:\Program Files\Common Files\CLAP

Documentation and licenses are in:
C:\Program Files\PRISMM\ShapeRack

To uninstall, close your audio hosts and remove ShapeRack from Windows
Settings > Apps > Installed apps. Projects using ShapeRack will require
the plugin to remain installed. Your personal preset files are retained.

Playback, stopped note previews, module presets, and multiple routed
sources were checked in FL Studio 2025. Project save/reopen remains untested.
