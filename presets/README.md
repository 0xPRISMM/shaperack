# ShapeRack presets

`Factory/` contains the five included racks as portable `.shaperack.json` files.
They contain all 153 audio parameters and can be loaded with **Import...**.

The installer creates `%APPDATA%\PRISMM\ShapeRack\Presets` and includes these
factory files in its `Factory` subfolder. The plugin also creates this folder
on first opening, including for ZIP installations. **Presets folder** opens
it in Windows Explorer. **Save...** puts your personal presets in the main
folder; **Refresh** updates the My presets menu after files are copied there.

Existing files are retained during updates and uninstall. Exported files can
also be stored anywhere you choose.
